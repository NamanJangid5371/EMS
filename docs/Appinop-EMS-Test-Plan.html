0. How to start

From the repository root, start the API and all three portals:

npm run dev:backend
npm run dev:admin
npm run dev:manager
npm run dev:employee
AppURL
Admin portalhttp://127.0.0.1:3000
Manager portalhttp://127.0.0.1:3001
Employee portalhttp://127.0.0.1:3002
API healthhttp://127.0.0.1:5000/api/health
Use a weekday for leave and attendance cases unless the case says weekend. Today’s sample dates assume August 2026 (Tue 18 is a weekday; Sat 22–Sun 23 is weekend).
